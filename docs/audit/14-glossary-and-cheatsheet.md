| Term | Context in Salvex Codebase | Practical Definition |
| :--- | :--- | :--- |
| **Salvage Asset** | Inventory condition type (`src/components/VehiclesPage.jsx`) | A vehicle declared an insurance total loss due to accidental collision, flood, or fire, sold for repair or component harvesting. |
| **Lot Number** | Unique identifier (`lot.id` / `salvex-103`) | The unique identifier assigned to an auction asset on the bidding floor. |
| **Starting Bid** | Financial threshold (`startingBid`) | The baseline price at which auction bidding commences. |

## 2. The Mental Model: "If You Only Remember 10 Things About This Project"

1. **It is an Interactive UI Prototype:**
   The application looks and feels complete, but runs 100% in browser memory with zero persistence and zero backend connectivity.
2. **The Design Will Change:**
   The client likes the current prototype, but the visual design is NOT final. Future features and redesigns are expected.
3. **Redesigning is Currently High-Friction:**
   Styling is implemented in massive vanilla CSS files (`App.css` 91KB, `SalvexAppComponents.css` 58KB) coupled to deeply nested DOM trees. Refactoring into modular UI primitives is needed.
4. **Virtual Routing is In-Memory Only:**
   Navigation is controlled by `currentRoute` state in `App.jsx`. There are no real URLs, browser back/forward buttons break, and refreshing `F5` returns to home.
5. **No Data Persistence:**
   All mutations (placing bids, approving KYC, adding listings) modify local React state and disappear on page refresh.
6. **Authentication is Simulated:**
   `LoginPage.jsx` accepts any credentials, and administrative controls (`AdminPanel.jsx`) have no real server-side authorization.
7. **Monolithic Components Exist:**
   `VehicleDetailsPage.jsx` contains 1,356 lines combining gallery logic, bid math, countdown intervals, modals, and layout.
8. **Semantic Color Naming Contradiction:**
   `--color-auction-red` in `index.css` is set to `#075BFF` (Royal Blue). Blue buttons are styled using classes with "red" in their names.
9. **Two Dead Dependencies in `package.json`:**
   `"lenis"` is installed but never imported; `"i"` is an accidental typo install from running `npm i i <package>`.
10. **Zero Automated Tests:**
   There are no unit, integration, or E2E tests configured. Business calculations (bidding increments, taxes) are untested.
