# Archive: pre-independent-audit documents (October 2026)

These are **historical, AI-generated audit and planning documents** produced during earlier
development of Salvex (mostly dated 2026-10-20). They were moved here unchanged on 2026-10-21,
before a fresh independent audit of the project.

**They are not authoritative.**

- They are not client requirements or business specifications.
- Many statements are outdated. For example, `audit/` was written before the FastAPI backend existed.
- Do not follow them blindly. Verify any claim against the current code before relying on it.

**The original client requirements document was not found in the repository** when this
archive was created.
